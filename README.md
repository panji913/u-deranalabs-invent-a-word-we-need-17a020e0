## The entry

> Textpect (v.) — to stare at the three pulsing dots of a typing indicator, waiting for a reply that never comes.

111 characters, 113 bytes — inside the gate of 1–140 characters.

## Why this word

- **A real gap.** Everyone who messages has stared at the three dots,
  waiting for a reply that never arrives. English has phrases for it
  ("left on typing…") and no single word.
- **Sayable, spellable, memorable.** *Text* + *expect*, collapsing in
  the middle the way *brunch* collapses breakfast + lunch. It sounds
  like English could have grown it.
- **Exact in one reading.** The definition is one line and
  self-contained: the dots, the staring, the reply that never comes.
- **Fresh.** A web check before writing found no existing use of
  "textpect" as a word (unlike "roomnesia", which is already in print
  and was rejected for that reason).
